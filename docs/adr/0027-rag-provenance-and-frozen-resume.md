# ADR-0027：RAG 来源、入选证据与冻结恢复

- 状态：已接受
- 日期：2026-10-12
- 关系：扩展 ADR-0015、ADR-0021、ADR-0024；不替代发布、权限与清理规则。

## 背景

Excel 检索内部已有叶子行来源，但公开 Trace、恢复与引用展示曾丢弃这些字段。
检索排名不等于回答上下文的编号，父块范围也不等于命中行；恢复时重新解析 current
Catalog 会把新版本误当成原 Run 证据。

## 决策

在既有 RetrievedChunk 添加可选且严格校验的来源，不建立 Citation Store。
公开 Trace 区分候选、实际 EvidencePack 和回答引用位置。数字引用合法性由确定性
校验完成；去掉非法编号，不重编号、不声明事实正确、不新增模型请求。

原生 RetrievalSnapshot 进入有界 Checkpoint，恢复使用相同 Tenant/版本/Collection/filter，
并通过既有 Catalog 检查撤销与清理状态。检查不是重新选 current；不恢复已清理版本，
不改变原有一小时替换保留期。无冻结快照的旧暂停 Checkpoint 明确拒绝继续检索，要求
重新提问；已完成旧消息仍显示文件/Page，不伪造行号。

## 不变量

- 叶子来源需绑定当前 RetrievedChunk 的 Document Version、文件与 L3 身份。
- 父块仅公开 S2 去重、有界的命中叶子；非连续行不得扩大成连续范围。
- 入选证据必须来自当前检索结果，或由同作用域父块真实命中叶子与已授权正文投影；
  叶子正文/hash/行来源先校验，不能从父块正文创造身份。数字引用只映射本次入选顺序。
- 来源说明与无编号父块上下文计入既有字符代理预算；不更改排序、图拓扑、Judge 评分规则或 HITL 策略。
- Run Event envelope 不变；SSE 和历史消息消费同一公开 Trace，缺省/null 均兼容。
- Checkpoint 不保存无界来源、私有推理、凭据或路径；新消息与旧消息可区分。

## 结果

无需数据库或 Milvus 迁移；来源链更可审计。增加来源校验与一次恢复可用性检查，且来源
标题会占用现有预算。身份合法不代表事实支持；严格行级审计可揭示宽父块引用污染，
但不自动纠正检索或回答策略。冻结快照也不提供无限期历史索引保留。
